# capy workflow scenes

six wide kawaii workflow illustrations generated with higgsfield `nano_banana_2_lite`, using `../logo-sticker.png` as the character and palette reference.

## production settings

- requested aspect ratio: `16:9`
- requested resolution: `1k`
- thinking: `HIGH`
- final delivery size: `1200 × 675` png
- visual system: warm brown capybara, cream muzzle, mint utility vest, orange action accents, powder blue and blush support colors, dark forest outlines, cream environment
- card treatment: centered primary action, strong silhouettes, restrained detail, symbolic interfaces, no readable copy

the model returned inconsistent native dimensions despite receiving `--aspect_ratio 16:9`. final files were proportionally fit and padded with the shared cream background to a true `1200 × 675`, preserving the full composition without stretching.
